# FX Director's Suite (fx-unified v5)
```bash
npm install
npm run dev        # http://localhost:3000
```
Requires Node 18.18+. Fonts (IBM Plex Sans Arabic, JetBrains Mono, Material Symbols) load from Google, so the first run needs internet.
Backend (optional, not used by the screens yet): set `FX_BACKEND_URL` (default http://127.0.0.1:4002); calls go through `/fx-api/*`.
`/brief /strategy /concept /script` are placeholders (their code was not in the delivery).
