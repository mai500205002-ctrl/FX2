## Brand & Style

The design system embodies "The Director's Suite" — an uncompromising, high-precision instrument tailored for Creative Directors, Executive Producers, Cinematographers, and elite Ad Agency leads orchestrating AI-native visual productions. 

The aesthetic is grounded in **Technical Minimalism infused with Cinematic Tactility**. It rejects the noisy, hyper-saturated trends of consumer AI tools in favor of calibrated control rooms, master grading suites, and high-end non-linear editing (NLE) environments. The user experience is focused, quiet, and hyper-legible, treating the creative vision as the primary subject on a deep carbon canvas.

Key visual attributes include:
- **Calibrated Darkness**: Pure, non-distracting obsidian values that prevent eye fatigue in dark grading rooms while providing zero color pollution.
- **Mastered Accents**: Luxurious Amber Gold denoting final executive intent, approval, and prime states, paired with an evocative AI Neural glow (Cyan Violet) reserved purely for computational inference and neural generation tasks.
- **RTL-Native Architectural Rigor**: Engineered natively for right-to-left layout dynamics with uncompromised typography rhythm, honoring structural Arabic forms before Latin translation.

## Colors

The palette simulates high-end optical glass, carbon hardware, and precision broadcast monitors. All surfaces are matte obsidian with controlled luminance progression.

### Core Tonal Progression
- **Canvas Base**: `#0B0D11` — The infinite root canvas; absorbs ambient glare.
- **Surface Layer 1**: `#11141A` — Primary container backgrounds, inspector panels, and sideboards.
- **Surface Layer 2**: `#171B22` — Floating cards, scene blocks, and timeline headers.
- **Surface Layer 3**: `#1E232D` — Hover states, modal overlays, and elevated popovers.

### Structural Lines
- **Hairline Border**: `#222733` — Universal 1px structural division.
- **Active Structural Border**: `#252B37` — Interactive borders and grid delimiters.
- **Emphasis Border**: `#323A4A` — Focus frames, selected scenes, and drag handles.

### Accents & Signal Colors
- **Amber Gold (Director's Cut)**: Primary `#D4AF37`, Highlight `#E5C158`, Deep Shade `#B89228`. Designates final master actions, render triggers, timeline playheads, and approved cuts.
- **Neural Cybernetic (AI Synthesis)**: Cyan `#38BDF8` transitioning to Violet `#818CF8`. Used exclusively for generative prompt states, diffusion runs, and computational synthesis pipelines.
- **Production State (Approved / In-Can)**: `#10B981` (active) / `#059669` (surface fill).

### Text Hierarchy
- **Chalk White**: `#F8FAFC` — High-priority script dialogue, timecodes, action verbs.
- **Muted Slate**: `#94A3B8` — Metadata labels, scene context, secondary camera directives.
- **Dim Charcoal**: `#64748B` — Inactive track rulers, grid increments, structural metadata.

## Typography

The type stack is architected around an Arabic-first typographic hierarchy supported by monospaced technical telemetry. 

### Font Role Distribution
- **Headers & Interface Body**: `IBM Plex Sans` (loaded with Arabic glyph sets like `IBM Plex Sans Arabic`). Its mechanical yet humanist structure captures the technical precision of scriptwriting, teleprompters, and studio cue cards. It provides exceptional balance in bidirectional English/Arabic contexts.
- **Production Telemetry & Timecodes**: `JetBrains Mono`. Dedicated strictly to numeric metadata, SMPTE timecodes (`01:23:45:12`), focal lengths (`35mm T1.5`), frame rates (`24.000 fps`), and prompt node IDs.

### RTL Script Considerations
- Avoid dense letter-spacing on Arabic body typography (`letter-spacing: 0` or standard ligatures preserved).
- Paragraph line-heights are set 10–15% more open than standard Latin systems to accommodate high vertical ascenders and descenders in Arabic script.
- Monospace tokens must strictly maintain uniform LTR rendering even within RTL layouts when expressing timecodes and aspect ratios.

## Layout & Spacing

The layout is a high-density, three-pane NLE (Non-Linear Editor) architecture built with fluid interior panes docked against fixed technical toolbars.

### Grid & Canvas Structure
- **Global Studio Shell**: Uses a 16-column desktop grid with dynamic panel splits:
  - **Right Panel (RTL Primary - Scene Navigation & Screenplay)**: 350px–420px contextual drawer.
  - **Center Canvas (Monitor & Timeline Viewport)**: Flexible fluid area.
  - **Left Panel (RTL Secondary - AI Generation & Parameter Inspector)**: 320px fixed inspector.
- **Mobile / On-Set Monitor Tablet**: Reflows into a single active viewport with a floating bottom-docked switcher allowing instantaneous toggling between Director's Monitor, Script View, and AI Node Graph.

### Layout Rhythm
- Tight micro-spacings (`space-xs` = 4px, `space-sm` = 8px) govern timeline tracks, audio meters, and tag ribbons to maximize screen real estate.
- Generous macro-spacings (`space-lg` = 24px, `space-xl` = 40px) isolate script prose, preventing visual fatigue during extended writing and directing sessions.

## Elevation & Depth

Depth is established strictly via tonal luminosity layering and precise 1-pixel micro-borders, avoiding muddy, diffuse drop shadows that compromise darkroom color calibration.

### Depth Mechanics
- **Ground Floor (`#0B0D11`)**: The master workplane. Zero elevation.
- **Docked Trays & Panels (`#11141A`)**: Outlined by 1px solid `#222733`. Depth is achieved through color contrast against the ground floor.
- **Active Scene Cards (`#171B22`)**: Outlined by 1px solid `#252B37`. Hovering triggers an immediate border transition to `#323A4A` and an ultra-subtle directional rim glow: `0 0 12px rgba(212, 175, 55, 0.08)`.
- **Floating Overlays & Modals (`#1E232D`)**: 1px solid `#323A4A` with an ambient occlusion shadow: `0 16px 36px rgba(0, 0, 0, 0.75)`.
- **AI Synthesis States**: Active generation blocks emit a controlled inner luminescence: `inset 0 0 16px rgba(56, 189, 248, 0.10)`.

## Shapes

The shape system is restrained and architectural (`roundedness: 1`). It employs deliberate 4px (`rounded-sm`) to 8px (`rounded-md`) corner radii to mirror camera bodies, studio rack-mount monitors, and physical switchers. 

- **Timeline segments, scrubbers, and cue markers**: Exactly 2px–4px radius; sharp and exact.
- **Scene cards, parameter inputs, and contextual toolbars**: 6px radius.
- **Overlays, modal dialogs, and video viewports**: 8px radius maximum.
- **Pill shapes (`rounded-full`)**: Strictly reserved for live recording tags (`REC`), approval chips, and timeline playhead needles.

## Components

### 1. Tactile Precision Buttons
- **Primary / Director's Cut Action**: Background `#D4AF37`, text `#0B0D11`, font-weight 600, radius 6px. On hover: `#E5C158`. Active: `#B89228` with a 1px depressed optical transform.
- **Secondary / Studio Utility**: Background `#171B22`, border 1px `#252B37`, text `#F8FAFC`. Hover: Border `#323A4A`, background `#1E232D`.
- **AI Neural Trigger**: Background `linear-gradient(135deg, rgba(56, 189, 248, 0.15), rgba(129, 140, 248, 0.15))`, border 1px `#38BDF8`, text `#38BDF8`.

### 2. Scene Screenplay Cards
- Built for bidirectional script writing.
- Header contains Arabic scene indexing (e.g., `مشهد ٠٤ - داخلي - ليل` / `SCENE 04 - INT - NIGHT`), followed by screenplay action and character cues.
- Integrated metadata ribbon hosting chips for:
  - **Camera**: Focal length, shot type (`35mm Anamorphic`, `Wide Angle`).
  - **Lighting**: Mood tags (`Golden Hour`, `Key 5600K`).
  - **Audio**: Sound beds, dialogue stems.
  - **Timing**: SMPTE range (`00:04:12:00 -> 00:04:30:15`).
- Left/Right border indicators: Approved cuts show a 2px `#10B981` leading edge; in-generation cards show a pulsing `#818CF8` neural line.

### 3. Metadata Chips & Status Badges
- Background `#11141A`, border 1px `#222733`, font `JetBrains Mono` 10px uppercase.
- Status variants:
  - **Approved**: Border `#059669`, background `rgba(16, 185, 129, 0.1)`, text `#10B981`.
  - **Rendering**: Border `#818CF8`, background `rgba(129, 140, 248, 0.1)`, text `#818CF8`.

### 4. Cinematic Timeline Tracks
- Dark Obsidian bed (`#0B0D11`) with micro-ruled frame markers in `#222733`.
- Clip blocks render with 1px inset outlines, thumbnail previews, waveform micro-graphs, and golden trim handles (`#D4AF37`) for active selection.
- Playhead: Needle `#D4AF37` with an ambient glow spanning the full canvas height.

### 5. Input Fields & Parameter Steppers
- Background `#0B0D11`, border 1px `#222733`, text `#F8FAFC`.
- Focus state: Border shifts to `#D4AF37` with `box-shadow: 0 0 0 1px #D4AF37`.
- Stepper values (ISO, Shutter Angle, Aspect Ratio) feature monospaced technical font with embedded scrub-dragging handles.
